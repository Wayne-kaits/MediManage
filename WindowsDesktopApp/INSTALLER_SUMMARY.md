### Method 1: Quick Install (Recommended)
1. Extract all files to a folder
2. Double-click `QUICK_INSTALL.bat`
3. Application starts immediately
4. Login with: `admin` / `admin123`

### Method 2: Full System Install
1. Extract all files to a folder
2. Right-click `FULL_INSTALL.bat` → "Run as Administrator"
3. Application installed to Program Files
4. Desktop and Start Menu shortcuts created
5. Login with: `admin` / `admin123`
